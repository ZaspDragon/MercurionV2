# Mercurion WMS

Render-ready Node/Express demo.

## Render Settings

Build command:

```bash
npm install
```

Start command:

```bash
npm start
```

Environment variables: none needed.

## Important

Do not paste `index.html` into `app.js`.

Each file must stay separate:
- app.js
- index.html
- main.js
- styles.css
- package.json
- receiving.js
- inventory.js
- transfer.js
- order_pulling.js
